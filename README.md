# 📊 Sales Analysis Dashboard | Power BI

An interactive **Sales Analysis Dashboard** built with Microsoft Power BI to transform sales data into clear, actionable business insights.

---

## 📌 Project Overview

This project focuses on analyzing sales performance from different business and customer perspectives.

The dashboard provides an interactive view of sales patterns across:

- 🕐 Time of Day
- 👥 Customer Demographics
- 💍 Marital Status
- 🎂 Age Groups
- 🏢 Departments
- 📦 Commodities

The goal is to help users quickly identify sales trends, customer segments, and top-performing product categories.

## 📈 Dashboard Highlights

### 🕐 Sales by Time of Day
Analyzes sales performance throughout different periods of the day to identify when sales activity is highest.

### 👥 Customer Analysis
Explores sales behavior across customer demographic segments, including:

- Age Groups
- Marital Status
- Customer characteristics

### 🏢 Top 5 Departments
Highlights the five departments generating the strongest sales performance.

### 📦 Top 5 Commodities
Identifies the top-performing commodities based on sales results.

### 🎯 Interactive Analysis
Users can interact with the dashboard through slicers and filters to dynamically explore different segments of the data.

---

## 💡 Key Business Questions

The dashboard helps answer questions such as:

1. Which time of day generates the highest sales?
2. Which age groups contribute most to sales?
3. How does marital status relate to sales performance?
4. Which departments are the top performers?
5. Which commodities generate the highest sales?
6. How do sales patterns change across different customer segments?
